# Geo

Web-App zur Visualisierung von Mathe für Schülerinnen und Schüler, gehostet über GitHub Pages:
https://trafalgaroutlaw.github.io/geo/

Kapitel:
- `dreieck.html`: verschiebbares Dreieck mit Winkeln und Fläche
- `potenzen.html`: Potenzen und Wurzeln (Klasse 9 Realschule)

Gemeinsames Design in `style.css`. Reines HTML/CSS/JS, kein Build-Schritt.
